- API_REFERENCE.md — alle 548 endpoints per router met mount-prefix

- ROLES_AND_PERMISSIONS.md — rollen, rechten, privacy
- INTEGRATIONS.md — externe koppelingen en status
- BACKGROUND_PROCESSES.md — jobs en achtergrondmechanismen
- FLAGS_SEED_DEMO.md — feature flags, seed-data, geen mockdata
- LIMITATIONS_AND_DEBT.md — beperkingen, technische schuld, productiestatus
- BUILD_INFO.md — versies, commit, omgevingsvariabelen
- FOLDER_TREE.txt / DB_TABLES.txt / PAGES.txt / COMPONENTS.txt / MOBILE_SCREENS.txt / ENGINES.txt — ruwe inventarissen
