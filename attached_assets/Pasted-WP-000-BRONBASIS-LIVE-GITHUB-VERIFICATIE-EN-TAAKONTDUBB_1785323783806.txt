FASE 1 — LIVE GIT-VERIFICATIE

Voer in de actuele repository minimaal uit:

git branch --show-current
git rev-parse HEAD
git log -1 --oneline
git status --short
git remote -v

Leg vast:

- repository;
- branch;
- volledige HEAD-SHA;
- korte SHA;
- laatste commitboodschap;
- remote origin;
- schone of gewijzigde working tree;
- eventuele lokale commits die niet gepusht zijn;
- eventuele afwijking tussen GitHub en Replit.

De geregistreerde kandidaat-SHA `666b702` mag pas als bronbasis gelden wanneer deze live wordt bevestigd.

Bij afwijking:

- gebruik de actuele live SHA als bronbasis;
- leg exact vast waarom die afwijkt;
- wijzig nog geen Build Pack;
- rapporteer welke werkpakketten opnieuw tegen de actuele SHA beoordeeld moeten worden.
