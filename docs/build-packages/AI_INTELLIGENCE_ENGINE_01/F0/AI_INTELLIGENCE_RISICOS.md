# AI_INTELLIGENCE_ENGINE_01 — F0 Risico's

| # | Risico | Toelichting | Beheersing |
|---|---|---|---|
| R1 | **Herleidbaarheid is verspreid, niet centraal** | Onderbouwing leeft in `analysis_feedback`-JSONB, render-time strings (`waaromAdvies`), uitleg-registry in code en de Explainability Engine — vier verschillende vormen. F1 moet aansluiten zonder de bestaande vormen te breken. | F1 bouwt het dossier als nieuwe laag; bestaande explainability wordt bron, niet slachtoffer. Regressietests op bestaande deterministische adviezen. |
| R2 | **Confidence bestaat in drie onvergelijkbare vormen** | observation-`computeConfidence`, foundation-engine-confidences en LLM-vrije-tekst. Eén standaard (F2) kan bestaande drempels (bijv. ≥2-signaal-guard) stilletjes verschuiven. | F2 mapt bestaande waarden expliciet; drempelgedrag vastleggen in tests vóór de omzetting. |
| R3 | **Legacy-adviezen zonder dossier** | Alles van vóór F1 (observaties, verdicts, voorstellen, race-evaluaties) mist dossiervelden. Verleiding: velden afleiden = verzinnen. | Status `LEGACY_NIET_VOLLEDIG_HERLEIDBAAR`; lege velden blijven leeg (zie legacy-inventarisatie in OPEN_PUNTEN_F0). |
| R4 | **Orchestrator-duplicatie** | Er zijn er al twee (foundation-run + today). F3 mag geen derde besliskern introduceren. | F3 breidt de foundation-orchestrator uit; today blijft presentatie-rangschikker. Grens vastleggen in F3-ontwerp. |
| R5 | **ai_foundation is flag-gated en niet volledig live** | De 7 engines draaien achter een flag; adviesoppervlakken in productiepad gebruiken deels oudere paden (day-advice, decideCoach-context). Dossierplicht "alle nieuwe adviezen" raakt dus twéé werelden. | F1 definieert "nieuw advies" per oppervlak; flag-status per oppervlak in het dossier zelf opnemen. |
| R6 | **Workflow-limiet & testlast** | Het workflow-plafond is bereikt; 14 fasen × tests betekent shell-runs en strikt sequentiële dist/-builds (bekende build-race). | Tests via `pnpm run test:x` in shell; build-semafoor respecteren. |
| R7 | **Parallel met Mirror-toets TESTDEPLOY/MEDIA_UITLEG** | Acceptatieomgeving staat bevroren op een vaste SHA; AIE-commits schuiven main door. | Acceptatieomgeving zit vast aan zijn eigen build; alleen na expliciete afstemming herbouwen. Fase-SHA's blijven per fase toetsbaar. |
| R8 | **Kosten/latency-groei** | Dossier + confidence + conflictdetectie voegen queries toe aan elk adviespad. | Per fase meten (F10-observability), geen dossier-writes in hot paths zonder async-pad. |
| R9 | **F9 wetenschappelijke citaties** | Geen bestaande live zoeklaag; extern zoeken introduceert verzonnen-citatie-risico en bronbetrouwbaarheidsvragen. | F9 alleen na expliciete go; anders eerlijk tonen dat de laag niet bestaat (F8-grens). |
| R10 | **Consent-matrix verbreedt** | Nieuwe purposes (doelbewaking, conflictvragen) hebben elk een consent-kind + minor-beleid nodig; vergeten = fail-closed uitval of, erger, lek. | Elke nieuwe purpose expliciet in de gateway-tabel met minorBlocked-besluit; test per purpose. |
