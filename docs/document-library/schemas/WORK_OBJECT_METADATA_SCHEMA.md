# Centraal metadata-contract voor werkobjecten

Verplichte velden:

- `object_id`
- `object_type`
- `title`
- `owner_user_id`
- `organisation_id` (optioneel)
- `team_id` (optioneel)
- `athlete_id` (optioneel)
- `event_id` (optioneel)
- `status`
- `version`
- `valid_from`
- `valid_until`
- `privacy_classification`
- `template_id`
- `template_version`
- `derived_from_object_id` (optioneel)
- `created_at`
- `created_by`
- `updated_at`
- `published_at` (optioneel)
- `withdrawn_at` (optioneel)
- `archived_at` (optioneel)

Relaties:

- deelnemers en rollen;
- secties;
- taken;
- opmerkingen;
- bijlagen;
- brongegevens;
- auditlog;
- exports.
