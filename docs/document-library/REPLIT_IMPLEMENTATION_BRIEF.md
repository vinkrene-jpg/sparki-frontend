# Replit-opdracht — centrale documentenbibliotheek

## Doel
Bouw één centrale documentenomgeving die alle meegeleverde sjablonen registreert, laat bewerken, versieert, dupliceert, publiceert, exporteert en archiveert.

## Centrale vindplaats
- Applicatie: `Meer → Documenten`
- Contextuele ingangen vanuit Club, Team, Trainer, Wedstrijd en Facturatie.
- Eén centrale zoek- en filterlaag.

## Minimale functies
- sjablooncatalogus;
- nieuw object uit sjabloon;
- nieuw eigen sjabloon door bevoegde beheerder;
- secties toevoegen/verwijderen waar toegestaan;
- concept, review, publiceren, intrekken, archiveren;
- versiegeschiedenis;
- dupliceren naar nieuwe situatie;
- opmerkingen, taken en bijlagen;
- rolgerichte weergaven;
- PDF-export;
- Excel/CSV waar het type dat vereist;
- organisatiegeheugen en evaluatie;
- audit.

## Niet bouwen
- tweede rapportgenerator;
- tweede rechtenlaag;
- losse documentsystemen per module;
- volledige boekhouding;
- automatische AI-publicatie.
