### Herstel (FIN-07/08 — hersteld én hertoetst)

De oorspronkelijke 500 was **geen defect in de F5-stafbezettingslogica zelf**,
maar een **migratiedrift in de gedeelde dev-database**. De hoofdagent heeft die
drift hersteld en de test opnieuw gedraaid (4/4 groen). Onderbouwing van de
oorspronkelijke root-cause:

- De selectie-POST synct de clubwedstrijd naar de eigen wedstrijdomgeving van de
  renner via `club-race-sync.ts`, met
  `ON CONFLICT (races.clerk_id, races.club_event_id) WHERE club_event_id IS NOT NULL`.
- Migratie `lib/db/migrations/0022_club_race_structure.sql` (regel 6–7) definieert
  de bijhorende partiële unieke index `races_club_event_unique`.
- **In de dev-DB ontbrak die index** (`pg_indexes` → 0 rijen; zie
  `logs/F5_staffing-rootcause.log`). Postgres gaf daardoor:
  `there is no unique or exclusion constraint matching the ON CONFLICT
  specification` → HTTP 500.

Kortom: de code en het schema (source-of-truth) waren consistent op a2e08175;
alleen de **dev-database was niet volledig gemigreerd** naar 0022.

**Herstel:** de ontbrekende index is idempotent aangebracht
(`CREATE UNIQUE INDEX IF NOT EXISTS races_club_event_unique ON races
(clerk_id, club_event_id) WHERE club_event_id IS NOT NULL;`), waarna
`test:club-race-staffing` opnieuw is gedraaid en 4/4 groen is.
