## Openstaande punten

- **OPEN PUNT — F9-01 (beperking, geen falen).** De admin-module wordt via de
  DEV-identiteitskiezer geopend met een QA-account dat geen admin-recht heeft;
  `/admin` en `/admin/ops` zijn daardoor niet via een echte admin-login
  gemeten (wel op hoogte/telefoonformaat, 933px = 1,1 scherm). De UX-regels voor
  admin zijn statisch/code-onderbouwd in `F9_ADMIN/VOOR_NA.md`. Dit is een
  bekende testomgevingsbeperking, geen UX-regressie.
